# AumDigital – Digital Goods Checkout for WooCommerce

No address when the cart is all virtual, paid virtual orders complete themselves, and the EU withdrawal consent a digital store needs.

- **WordPress.org:** https://wordpress.org/plugins/aumdigital/
- **Website:** https://aumcreate.com
- **Support:** support@aumcreate.com

## About this repository

This is the released source of the plugin, exactly as published on WordPress.org — one commit per release, tagged with the version. Bug reports and pull requests are welcome here; fixes are folded into the next release.

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for *AumDigital – Digital Goods Checkout for WooCommerce*), or download a release from this repository's tags and upload the ZIP.
